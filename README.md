# Leer es viajar

A literary map where readers log the books they read tied to a destination —real or fictional— and track their reading in kilometers.

In beta with real testers: [beta.leeresviajar.app](https://beta.leeresviajar.app)

Static frontend (classic HTML/CSS/JS, no build step) + Supabase (auth and data). Maps powered by Leaflet.
